Use the question numbers at the bottom to move between questions. Use the arrows to go to the previous or next question.

Setting changes text size and background colour. Notepad opens a private notepad. Finish section ends this section when you are ready (or when time is up).

Task help

Read the instructions for each question carefully. You can change an answer at any time before you finish the section.

To highlight text, select it and right-click (or use the highlight colours). To clear a highlight, right-click it and choose Clear or Clear all.

Listening answers are usually one word and/or a number unless the question says otherwise. Writing has no spellcheck, as in the real test.
